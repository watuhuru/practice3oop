# Ответы к заданиям 1–4

1. Для созданного объекта `f` допустимы вызовы 1, 2, 3, 4, 6 и 8. Вызовы 5 и 7 ошибочны: поле `i` и метод `imethod()` принадлежат экземпляру, поэтому через имя класса к ним обратиться нельзя. К статическим членам предпочтительно обращаться через `F`, хотя обращение через объект компилируется.
2. `main` и `factorial` можно объявить `static`; `getCount` остаётся методом экземпляра, так как использует поле `count`.
3. Из статического `main` можно обратиться к методам и полям экземпляра через созданный объект. Метод экземпляра может использовать статические члены класса.
4. Новый массив ссылок заполнен значениями `null`. Вывод `dates[0]` покажет `null`, а вызов `dates[0].toString()` без создания объекта вызовет `NullPointerException`.
