# Практическая работа №3 — часть 3

## Задания

1. `TwoNumberCalculator` — калькулятор для двух введённых чисел с четырьмя операциями.
2. `CountrySelector` — выпадающий список стран и сведения о выбранной стране.
3. `TextEditor` — окно с меню «Файл», «Правка», «Справка», двумя кнопками и текстовым полем. Текст можно сохранить в UTF-8.
4. `ButtonCalculator` — калькулятор с числовыми кнопками и кнопками операций.

Исходники находятся в `src/practice3/part3`. Откройте папку `src` как корень исходников в IntelliJ IDEA и запустите нужный класс с методом `main`.
