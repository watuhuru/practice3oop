# Практическая работа №3 — часть 1

## Задания

1. `MatchScore` — табло матча AC Milan и Real Madrid с кнопками, счётом, последним автором гола и победителем.
2. `RandomShapes` — 20 случайных фигур разных цветов с общим абстрактным классом Shape.
3. `ImageViewer` — отображение изображения, путь к которому передаётся первым аргументом командной строки.
4. `AnimationDemo` — покадровая анимация. Без аргументов показывает встроенный пример; вместо него можно передать пути к файлам кадров в нужном порядке.

Исходники находятся в `src/practice3/part1`. Откройте папку `src` как корень исходников в IntelliJ IDEA и запустите нужный класс с методом `main`. Для задания 3 укажите путь к картинке в аргументах запуска.
